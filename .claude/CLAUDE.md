# system-skills

This repository is a Claude Code plugin marketplace with one plugin, `system`, whose root is the repository root. Its skills operate the maintainer's machine setup, so what they act on (the dotfiles repositories, the blueprint, the machines) belongs to a neighbouring project, System; this repository owns only the skills. The README says how the plugin is installed and released.

The maintainer's project documentation is in Notion and its work is tracked in Linear; the front matter points to both, and they are private. Nothing personal is committed here.
